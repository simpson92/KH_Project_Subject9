# Day 01 검사 문제 정의

## ROI 비교 결과 (교재 15절)

### ROI를 맞춘 기준

sample01(640×640)의 병뚜껑을 기준으로, 뚜껑 전체와 아래 병 입구 일부가 들어오도록 설정했다.

### 결과 기록 (최종 ROI: x1=150, y1=100, x2=480, y2=500)

| 이미지 | 실제 상태 | ROI 결과 | 관찰 |
|---|---|---|---|
| sample01 | 뚜껑 있음 | 성공 | 기준 이미지. 뚜껑이 가장 위쪽(위끝 y≈138)에 있어 위 여유가 가장 작음 |
| sample02 | 뚜껑 있음 | 성공 | 뚜껑이 sample01보다 아래에 있음. 아래 여유가 약 28px로 가장 작음 |
| sample03 | 뚜껑 있음 | 성공 | sample02와 비슷한 위치. 좌우 · 상하 모두 안쪽에 들어옴 |
| sample04 | 뚜껑 없음 | ROI 정상 | 같은 위치에 나사산이 보임. 검사 위치는 맞지만 뚜껑이 없는 불량 이미지 |
| sample05 | 뚜껑 없음 | ROI 정상 | sample04와 같은 병 입구 영역. 투명한 나사산만 보임 |

### ROI 변경 과정

1차 ROI (03번): (150, 100, 480, 500) — sample01 한 장에서는 뚜껑이 잘 들어옴
2차 ROI (04번 일괄 적용): (150, 150, 480, 500) — sample01의 뚜껑 윗부분 약 12px이 잘림
→ 같은 정상 제품인데 ROI가 제품을 다 담지 못한 "검사 영역 문제"
최종 ROI: (150, 100, 480, 500) — 5장 모두 뚜껑이 들어오고, 뚜껑 높이가 달라도 위 · 아래 여유가 남음

### 구분해야 할 것

- ROI 실패: 검사해야 할 위치를 제대로 포함하지 못한 경우 (예: 2차 ROI의 sample01)
- 제품 불량: ROI 위치는 맞지만 그 안에 병뚜껑이 없는 경우 (sample04 · sample05)

### 배운 점

한 장에서 잘 맞는 ROI ≠ 모든 이미지에서 잘 맞는 ROI.
뚜껑 높이가 사진마다 달라서(위끝 y≈138~192), 위아래 여유가 필요했다.

## Mini Challenge — 주황 뚜껑 약병 (교재 19~23절)

### 1. 검사 대상
검사할 제품: 투명 PET 약병의 주황색 PP 뚜껑

### 2. 정상 조건
정상 상태: 병 입구에 주황 뚜껑이 닫혀 있음 (ok_01 ~ ok_03)

### 3. 불량 조건
불량 상태: 뚜껑이 없어 투명한 나사산이 드러남 (ng_01, ng_02)

### 4. 검사 ROI (최종)
x1 = 395
y1 = 120
x2 = 915
y2 = 330
(사진 크기 1265×1012 기준)

### 5. 왜 이 영역을 ROI로 선택했는가?
뚜껑 유무는 병 입구 위쪽만 보면 판단할 수 있다. 라벨·배경은 필요 없으므로 제외하고,
뚜껑이 있어야 할 자리(뚜껑 + 바로 아래 병 입구)만 포함했다.
병을 좌우로 옮겨 찍은 사진도 들어오도록 뚜껑 좌우에 여유를 두었다.

### 6. 여러 이미지에 같은 ROI를 적용한 결과

1차 ROI (460, 140, 840, 310) — ok_01의 뚜껑에 바짝 맞춤

| 이미지 | 결과 | 관찰 |
|---|---|---|
| ok_01 | 성공 | 기준 이미지. 뚜껑이 딱 맞게 들어옴 |
| ok_02 | 부분 성공 | 병이 왼쪽으로 이동 → 뚜껑 왼쪽 36px 잘림 |
| ok_03 | 부분 성공 | 병이 오른쪽으로 이동 → 뚜껑 오른쪽 45px 잘림 |
| ng_01 | ROI 정상 | 뚜껑 자리에 투명한 나사산이 보임 |
| ng_02 | ROI 정상 | 같은 위치를 보고 있음. 병 입구 왼쪽 끝이 살짝 걸침 |

최종 ROI (395, 120, 915, 330) — 좌우 약 65px, 상하 약 20px 여유 추가

| 이미지 | 결과 | 관찰 |
|---|---|---|
| ok_01 | 성공 | 좌우 여유 69 / 78px |
| ok_02 | 성공 | 가장 빠듯한 왼쪽도 29px 여유 |
| ok_03 | 성공 | 가장 빠듯한 오른쪽도 30px 여유 |
| ng_01 | ROI 정상 | 병 입구 전체가 들어옴 |
| ng_02 | ROI 정상 | 병 입구 전체가 들어옴 |

### 7. ROI 판단
- ROI 범위를 조금 넓혀야 함
  (병이 좌우로 약 86px 움직이는 범위 안에서는, 넓힌 고정 ROI로 사용 가능)

### 8. 눈으로 보이는 정상·불량의 차이
정상은 ROI 안의 대부분이 주황색 뚜껑으로 채워져 있다.
불량은 같은 자리가 투명한 나사산과 뒤쪽 배경(모니터)으로 보인다.

### 9. 컴퓨터가 나중에 측정할 수 있을 것 같은 값
- 색상: ROI 안에서 주황색이 차지하는 비율
- 면적: 뚜껑 영역의 크기 (Area Ratio)
- 위치: 뚜껑 윗면의 높이 (뚜껑이 없으면 병 입구가 더 낮게 보임)

### 10. 현재 검사 가설
ROI 안에서 주황색 픽셀의 비율을 측정하면,
뚜껑이 있는 상태와 없는 상태를 구분할 수 있을 것이다.

### 11. 아직 모르는 것
- 주황색을 어떤 방법(Gray / HSV 등)으로 분리할지 아직 모른다.
- 정상과 불량을 나눌 실제 기준값은 아직 모른다.
- 조명이 바뀌거나 병이 더 크게 움직이면 어떻게 될지 확인하지 않았다.
